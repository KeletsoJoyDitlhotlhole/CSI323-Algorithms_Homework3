# 🧠 Algorithms & Data Structures

A collection of **Java algorithm exercises and homework** completed during my Computer Science studies at university. 🎓💻

This repository documents some of my earlier work with algorithms, data structures, computational problem-solving, and algorithmic thinking.

## 🌸 About This Repository

These exercises were completed as part of my university coursework while learning how to design and implement efficient solutions to computational problems.

The repository includes problems involving arrays, searching, ranges, strings, permutations, and tree traversal.

Looking back at these exercises is a nice reminder of where my journey in Computer Science started and how much my approach to problem-solving has grown since then. 🌱✨

## 📚 Algorithms Included

### 🔢 Array & Searching Problems

- `Distinct.java` — Working with distinct values within a collection.
- `IncreasingArray.java` — Array manipulation and sequence-based problem solving.
- `MaximumSubarray.java` — Finding a maximum subarray within a sequence.
- `MissingNum.java` — Finding a missing value within a number sequence.
- `SumOfTwoValues.java` — Finding two values that satisfy a target sum.
- `SumOfThreeValues.java` — Extending target-sum searching to three values.

### 📏 Range Problems

- `_RangeContains.java` — Working with containment relationships between ranges.
- `NestedRangesCheck.java` — Checking relationships between nested ranges.

### 🔤 Strings & Combinatorics

- `StringMatching.java` — Working with string matching and search problems.
- `Permutations.java` — Generating and working with permutations.

### 🌳 Trees

- `TreeTraversals.java` — Exploring tree traversal algorithms and techniques.
